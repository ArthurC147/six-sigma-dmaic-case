# DMAIC — Define Phase

## Project Charter

**Process:** IT Helpdesk ticket resolution
**Problem statement:** Network-category tickets show the highest resolution
time and the highest total volume of any category, consuming 59% of all
process hours logged — well above what a healthy SLA-compliant process
should require.

**Goal statement:** Reduce mean resolution time (MTTR) for Network tickets
without increasing headcount, using standard DMAIC methodology.

**SLA target:** 24 hours per ticket (business-defined threshold used
throughout this project).

**Scope:** Network-category tickets only. Other categories are measured
for context (Pareto) but are out of scope for the improvement action in
this cycle.

**Stakeholders:** Helpdesk team, IT infrastructure team, end users.

## Business case

This case study mirrors a real Six Sigma DMAIC project applied to a
technical support ticket workflow, which achieved a documented **13%
reduction in MTTR** (Lean Six Sigma Yellow Belt certification, Vivo
Academy). The dataset used here is public (Kaggle-style helpdesk data),
not the original confidential dataset — the same methodology is applied
end-to-end to demonstrate the approach.
